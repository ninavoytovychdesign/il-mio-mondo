# Pasetto – документація

**Pasetto** (раніше «Il mio mondo») – Android-застосунок із наочними рутинами й звуковими книжечками для маленьких дітей. Він для всіх малих, зокрема для дітей із РАС чи затримкою мовлення, а батьки налаштовують усе у своїй зоні.

Стан на 27.10.2026: Flutter-версія готова, AAB 0.3.0 підписаний, усе для закритого тесту в Google Play підготовлено.
